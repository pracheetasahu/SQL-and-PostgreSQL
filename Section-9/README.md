# SQL Subqueries – Section 9

## Overview

This section contains SQL practice exercises focused on subqueries using PostgreSQL. The exercises use the `phones` table to practise nested queries, aggregate functions, and calculations within SELECT, WHERE, and FROM clauses.

## Exercises Completed

| Exercise | Topic | Concepts |
|---|---|---|
| 1 | Embedding in Select | Subqueries in SELECT, aggregate functions |
| 2 | From-less Selects | Scalar subqueries, MAX, MIN, AVG |
| 3 | Practice Your Subqueries! | Subqueries, ALL operator |
| 4 | Subquery Where's | Subqueries in WHERE clauses |
| 5 | Subquery From's | Subqueries in FROM clauses, GROUP BY, AVG, MAX |

## Concepts Practised

- Using subqueries inside SELECT statements.
- Retrieving maximum, minimum, and average values.
- Comparing values with subquery results.
- Filtering records using subqueries in WHERE clauses.
- Calculating aggregate values for each manufacturer.
- Using subqueries in the FROM clause.
- Renaming calculated columns using aliases.

Practised writing nested SQL queries and using subqueries with aggregate functions in SELECT, WHERE, and FROM clauses.
