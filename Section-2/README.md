# SQL Basics – Exercises 3 to 7

## Overview

This folder contains SQL practice exercises completed using PostgreSQL as part of the Udemy SQL and PostgreSQL course.

## Exercises Completed

| Exercise | Topic | Concepts |
|---|---|---|
| 3 | Practicing WHERE Statements | WHERE, comparison operators |
| 4 | A More Challenging WHERE | WHERE, OR |
| 5 | Trying Calculations in WHERE Clauses | Arithmetic expressions, AS, WHERE |
| 6 | Try Updating Records in a Table | UPDATE, SET, WHERE, SELECT |
| 7 | Practice Deleting Records | DELETE, WHERE, SELECT |

## Concepts Practised

- Filtering records using WHERE.
- Combining conditions using OR.
- Performing calculations in SQL queries.
- Renaming calculated columns using AS.
- Updating existing table records.
- Deleting records based on conditions.
- Retrieving records using SELECT.

Practised SQL filtering, calculations, record modification, and deletion using PostgreSQL.
