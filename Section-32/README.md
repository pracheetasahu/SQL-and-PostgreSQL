# Section 32 – Schema and Data Migrations

## Overview
In this section, we learn how to make changes to a database and update existing data.

## Topics Covered
- Adding a new column to an existing table.
- Understanding schema migrations.
- Understanding data migrations.
- Using SQL to change the database structure.
- Using JavaScript to update existing records.
- Converting longitude and latitude values into a POINT value.

## Files
- `Schema_and_Data_Migrations.sql` – Contains SQL commands for changing the database structure.
- `index.js` – Creates a simple Express application to display and add posts.
- `01-lng-lat-to-loc.js` – Updates existing posts by converting longitude and latitude into POINT values.

## Purpose
These files help us understand how to change a database structure and update existing data without losing the existing records.
