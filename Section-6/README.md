# Section 6 – Group By and Inner Join Review

## Overview

This section focuses on practising SQL grouping and inner join operations using an e-commerce database containing users and orders.

## Exercises Completed

| Exercise | Topic | Concepts |
|---|---|---|
| 1 | Group By Review | GROUP BY, COUNT |
| 2 | Inner Join Review | INNER JOIN, ON |

## Concepts Practised

- Grouping orders based on their payment status.
- Counting paid and unpaid orders.
- Combining users and orders tables.
- Retrieving user names along with their order payment status.
- Joining related tables using matching IDs.

## Technology Used

- PostgreSQL
- SQL
- GitHub

## Learning Outcome

Improved understanding of aggregate functions, grouping records, and joining related database tables using SQL.
