# Section 4 – SQL Joins

## Overview

This section covers SQL JOIN operations using a book publishing database. The exercises demonstrate how to retrieve related information from multiple tables.

## Exercises Completed

| Exercise | Topic | Concepts |
|---|---|---|
| 1 | Practice Joining Data | INNER JOIN |
| 2 | Joins, Joins, Join! | LEFT JOIN |
| 3 | Three Way Exercise | Multiple JOIN operations |

## Concepts Practised

- Combining records from related tables.
- Retrieving book titles and author names.
- Using INNER JOIN to find matching records.
- Using LEFT JOIN to retain all records from the left table.
- Joining three tables to retrieve book, author, and review information.
- Applying multiple join conditions.

## Technology Used

- PostgreSQL
- SQL
- GitHub

## Learning Outcome

Gained practical experience with SQL joins and learned how to retrieve related information from two or more database tables.
