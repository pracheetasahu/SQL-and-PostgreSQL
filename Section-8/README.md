# Section 8 – Merging Results with UNION

## Overview

This section contains a SQL practice exercise focused on combining the results of multiple SELECT queries using the UNION operator.

## Topic Covered

- UNION
- SELECT statements
- WHERE
- GROUP BY
- HAVING

## Concepts Practised

- Retrieving manufacturers based on phone prices.
- Grouping records by manufacturer.
- Filtering grouped records using HAVING.
- Combining results from multiple queries using UNION.
- Removing duplicate records from combined results.
