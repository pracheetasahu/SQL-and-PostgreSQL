# Section 35 – User Repository and SQL Injection

- Learned the Repository Pattern to organize database queries.
- Created `UserRepo` methods: `find`, `findById`, `insert`, `update`, and `delete`.
- Used `toCamelCase()` to convert database column names into JavaScript camelCase.
- Learned about SQL injection and how malicious input can affect database queries.
- Used parameterized queries with `$1`, `$2` to prevent SQL injection.
- Practised CRUD operations using Express routes.
- Used `RETURNING *` to get inserted, updated, or deleted rows.
- Tested API endpoints using Postman or VS Code REST Client.
