# Section 5 – Grouping and Aggregating

## Overview

This section focuses on grouping records and performing aggregate calculations using SQL. The exercises use book publishing and phone sales datasets.

## Exercises Completed

| Exercise | Topic | Concepts |
|---|---|---|
| 1 | Practice For Grouping and Aggregating | GROUP BY, COUNT |
| 2 | Grouping With a Join! | JOIN, GROUP BY, COUNT |
| 3 | Practice Yourself Some Having | SUM, GROUP BY, HAVING |

## Concepts Practised

- Grouping records using GROUP BY.
- Counting records using COUNT().
- Combining tables before aggregation.
- Calculating total revenue using SUM().
- Filtering grouped results using HAVING.
- Applying aggregate functions to grouped data.

## Technology Used

- PostgreSQL
- SQL
- GitHub

## Learning Outcome

Developed practical knowledge of SQL aggregation, grouping, and filtering summarized results.
